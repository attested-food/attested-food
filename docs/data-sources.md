# Fallback data sources (India)

Third-party sites that publish lab test results for products sold in India, across any packaged food or supplement category. Used only as **fallback** data when no verified user lab report exists (see [idea.md](idea.md#two-data-layers)). Always shown with source attribution and a link back. Results published as PDFs are acceptable.

Checked Nov 2026. Check each site's terms before scraping.

| Source | Coverage | What it shows | Sample |
|---|---|---|---|
| Unbox Health | Broad Indian packaged food plus supplements: cereals and muesli, snacks, biscuits, ghee, oils, honey, noodles, protein and more | Grade A+ to D, labs used (Eurofins, ALS), batch no., **label claim vs tested value** with an accuracy score per parameter, toxins (aflatoxin, lead, mercury). Report PDFs require login. | https://www.unboxhealth.in/explore/product/patanjali-cow-ghee/0ecbe039-9606-4e5d-8df9-b7b4e2299fa3 |
| Trustified | Mostly Indian protein and supplement brands (MuscleBlaze, Avvatar, AS-IT-IS, Nutrabox, Nakpro, The Whole Truth, Mille...), a few foods | Pass/fail per batch, tested by Eurofins, published date; label accuracy, amino and melamine spiking, heavy metals, aflatoxins, pesticides (some values only as images) | https://www.trustified.in/passandfail/truebasicsplantprotein |
| Labdoor | US site that has graded a few Indian protein products (MuscleBlaze, Bal Bharat, MyProtein India) | Grade, label accuracy, purity, safety scores | https://labdoor.com/review/muscleblaze-biozyme-performance-whey |
| Consumer Voice (VOICE magazine) | Indian comparative lab tests of named brands across food categories | Per-brand test values in PDF reports | https://consumeraffairs.nic.in/sites/default/files/file-uploads/ctocpas/corn%20flakes-12.pdf |
